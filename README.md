# ⚡ VoltStore — магазин электроники

Учебный интернет-магазин электроники на **React + TypeScript**. Каталог товаров с поиском, фильтрацией по категориям, страницей товара и корзиной, которая сохраняется между визитами.

> 🔗 **Демо:** https://electro-shop-ashen.vercel.app

## Возможности

- 🛍️ Каталог товаров, загружаемый с публичного API (DummyJSON)
- 🔍 Поиск по названию с debounce
- 🏷️ Фильтрация по категориям (смартфоны, ноутбуки, планшеты, аксессуары)
- 📄 Отдельная страница товара с деталями
- 🛒 Корзина: добавление, изменение количества, удаление, подсчёт суммы
- 💾 Сохранение корзины в `localStorage`
- ⏳ Состояния загрузки, ошибки и «ничего не найдено»
- 📱 Адаптивная вёрстка

## Стек

- **React 18** + **TypeScript**
- **React Router** — маршрутизация между страницами
- **Context API** — глобальное состояние корзины
- **CSS Modules** — изолированные стили
- **Vite** — сборка и dev-сервер
- **DummyJSON** — источник данных о товарах

## Запуск

Нужен Node.js 18+.

```bash
# установить зависимости
npm install

# запустить dev-сервер (http://localhost:5173)
npm run dev

# собрать production-версию
npm run build

# посмотреть собранную версию локально
npm run preview
```

## Структура проекта

```
src/
├── api/          # запросы к API
├── components/   # переиспользуемые компоненты (в т.ч. ui/)
├── context/      # CartContext — состояние корзины
├── hooks/        # useDebounce, useCart
├── pages/        # страницы (каталог, товар, корзина, 404)
├── types/        # типы TypeScript
├── utils/        # константы и хелперы
└── styles/       # глобальные стили и CSS-переменные
```

## Источник данных

Данные о товарах берутся из [DummyJSON](https://dummyjson.com/) — бесплатного тестового API.
Используются категории `smartphones`, `laptops`, `tablets`, `mobile-accessories`.
